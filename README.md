- **[New pattern banks for Mutable Grids](https://eight4awish.com/notes/grids-patterns/)**: Sorrow's derived drum maps are the same data structure Grids uses, so they drop straight into the real module. Three new banks, but no hardware to test them on.

## Software around the modules

**Retrospective** is a menu-bar Mac app that keeps buffering every channel of your audio interface, so a press of a button saves the last few minutes as WAV files, for when the best thing you played wasn't being recorded. A 1U USB-MIDI button, the ESP32 ClkLinkRec over WiFi, and the menu bar itself can all trigger it. It's in [seeed-recorder](https://github.com/Eight4aWish/seeed-recorder).

<p>
  <img src="public/images/retrospective.jpeg" alt="The Retrospective trigger module" height="100">
  <img src="public/images/retrospective-settings.png" alt="Retrospective's settings" height="200">
</p>

**CortHex's web app** takes a description of a sound in words and has an LLM build a bank of patches for the module's six CVs, which you can save and recall between sessions. The module and its LLM proxy are in [eurorack_modules](https://github.com/Eight4aWish/eurorack_modules/tree/main/src/nanoesp32_corthex).
