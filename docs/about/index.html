About

DIY eurorack, built the way software gets built: the panel, the circuit and the music all written as code, then made real.

Everything here is open: firmware, panel models, netlists and patches. The tutorials cover the three workflows behind it — Strudel for the music, build123d for the panels, and the N8Synth layout tool for the circuits.
